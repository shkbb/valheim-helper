ENGLISH

INSTALL
1. Close Valheim.
2. Run install.bat: it finds the game in Steam by itself.
   (Or by hand: copy the contents of the "game" folder into the game folder,
   where valheim.exe is.)
3. Start the game as usual. Menu: F7 or Insert (close it with the same key or Esc).
   The keys can be changed in Settings -> Keys.
To remove the mod, run uninstall.bat.

EDITIONS
The mod comes in three editions; this archive is one of them
(Settings -> Updates shows which).
- Legal:  map, wiki guide, free camera and photo mode, statistics, building view
          modes, achievement list with the state in the game and in Steam.
          No advantage in the game.
- Helper: Legal + crafting from nearby chests, picking up everything around,
          chest sorting and base storage, filling smelters and torches,
          tamed animals, the game's own world modifiers.
- Full:   everything, cheats included (god mode, flying, items, skills, time and
          weather, building without resources, map teleport, unlocking achievements).
To switch, download another edition and install it over this one.

UPDATES
When the game starts, the mod checks GitHub for a newer version, downloads it in
the background and installs it the next time you start the game.
Settings -> Updates: turn the check off, or check now. The wiki guide updates
itself separately, straight from the wiki.

LANGUAGES
Menu: English, Ukrainian, German, French, Spanish, Polish (more coming).
"As the game's language" follows the language Valheim runs in. Settings -> Language;
a change applies after restarting the game.
Wiki guide: Ukrainian, English, German, French, Polish, Portuguese, Czech, Chinese.
The language of the articles is switched by the button at the top right of the guide.

WHERE THINGS ARE
- Map (M): the panel on the right: layers (places, resources of the whole world,
  tamed animals), search, your markers (Alt + click), drawings (Ctrl + drag),
  view settings including "show unexplored" (never saved to the character).
- Guide: the Valheim wiki inside the game, with pictures and tables, offline.
- Base (Helper, Full): Storage, Do not touch, Smelters, Torches, Animals.
- Achievements: Settings -> Achievements.

ВСТАНОВЛЕННЯ
1. Закрий Valheim.
2. Запусти install.bat — він сам знайде гру в Steam.
   (Або вручну: скопіюй вміст папки "game" у папку гри, де лежить valheim.exe.)
3. Запускай гру як завжди. Меню: F7 або Insert (закривається ними ж або Esc).
   Клавіші можна змінити в "Налаштування" -> "Клавіші".
Прибрати мод — uninstall.bat.

РЕДАКЦІЇ
Мод має три редакції, цей архів — одна з них
(яка саме — видно в "Налаштування" -> "Оновлення").
- Легальна: карта, довідник-вікі, вільна камера й фоторежим, статистика, режими
            перегляду будівель, список досягнень зі станом у грі та в Steam.
            Жодної переваги в грі.
- Помічник: Легальна + крафт зі скринь поруч, "Підібрати все довкола", сортування
            скринь і склад бази, заповнення печей і факелів, приручені тварини,
            змінники світу самої гри.
- Повна:    усе, з читами (безсмертя, політ, видача предметів, навички, час і погода,
            будівництво без ресурсів, телепорт з карти, виконання досягнень).
Щоб змінити редакцію, завантаж іншу й встанови поверх.

ОНОВЛЕННЯ
Під час запуску гри мод сам перевіряє на GitHub, чи вийшла новіша версія, тихо
завантажує її й встановлює під час наступного запуску гри.
"Налаштування" -> "Оновлення": вимкнути перевірку або перевірити зараз.
Довідник оновлюється окремо, просто з вікі.

МОВИ
Меню: українська, англійська, німецька, французька, іспанська, польська (далі буде).
"Як мова гри" — мова, якою запущено Valheim. "Налаштування" -> "Мова";
зміна діє після перезапуску гри.
Довідник: українська, англійська, німецька, французька, польська, португальська,
чеська, китайська. Мову статей перемикає кнопка вгорі праворуч у довіднику.

ДЕ ЩО ШУКАТИ
- Карта (M): панель праворуч — шари (місця, ресурси всього світу, приручені тварини),
  пошук, свої мітки (Alt + клік), малюнки (Ctrl + тягнути), вигляд, зокрема
  "показати невідкрите" (у сейв персонажа не пишеться).
- Довідник: вікі Valheim просто в грі, з картинками й таблицями, без інтернету.
- База (Помічник, Повна): Склад, Не чіпати, Печі, Факели, Тварини.
- Досягнення: "Налаштування" -> "Досягнення".

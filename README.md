# Valheim Helper

Мод для Valheim (власний світ і гра з друзями): карта, вбудований довідник-вікі українською та іншими мовами, вільна камера,
помічник для бази (печі, факели, сортування скринь), меню читів і помічник досягнень. Інтерфейс українською й англійською.

## Встановлення
Закрий гру, розпакуй архів із [Releases](../../releases), запусти `install.bat` (сам знайде Valheim у Steam). Меню: F7 або Insert.

## Збірка
Потрібні .NET SDK і Valheim (посилання на збірки гри — у `ValheimHelper/ValheimHelper.csproj`).
BepInExPack для Valheim (5.4.2350) розпакувати в `deps/BepInExPack` — з нього беруться `winhttp.dll` і Harmony.

```powershell
.\build.ps1            # збірка, тести, архів у dist\
.\pack_lite.ps1        # легкий архів без пакетів довідника
```

Як мод обходить блокування досягнень і як усе влаштовано — `ARCHITECTURE.md`.
